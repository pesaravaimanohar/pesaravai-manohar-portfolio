# Pesaravai Manohar · Portfolio

A responsive, animated React portfolio for Pesaravai Manohar, a web developer based in Bengaluru. Built with React, Vite, CSS, and accessible browser APIs.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Vercel uses the settings in `vercel.json` to build the site from the repository root and serve the `dist` output. The site includes About, Skills, Projects, and Contact sections, responsive navigation, reduced-motion support, and animated glowing section dividers.
